Equações e inequações trigonométricas

Encontre conjuntos de soluções, respeite a periodicidade e interprete desigualdades no círculo unitário.

Conteúdo de apoio em ampliação: esta versão oferece explicações, exemplos e exercícios iniciais. As futuras apostilas autorais e avaliações serão acrescentadas pelos responsáveis e o texto deve passar por revisão matemática e editorial.

1. Por que uma solução não basta

As funções trigonométricas são periódicas: se sen x = a, também sen(x + 2kπ) = a para todo inteiro k. Resolver uma equação exige descrever todas as soluções ou apenas as que pertencem ao intervalo pedido.

sen(x + 2kπ) = sen x; cos(x + 2kπ) = cos x; tg(x + kπ) = tg x (k ∈ ℤ)

Antes de resolver, identifique a unidade do ângulo, o domínio e o período. As equações sen x = a e cos x = a não têm solução real quando |a| > 1.

2. Equações fundamentais

Para |a| ≤ 1, seja α = arcsen(a), valor principal entre −π/2 e π/2. Então as soluções de sen x = a podem ser escritas em duas famílias:

x = α + 2kπ ou x = π − α + 2kπ, k ∈ ℤ.

Para cos x = a, com β = arccos(a) ∈ [0,π], temos x = ±β + 2kπ. Para tg x = a, temos x = arctg(a) + kπ.

Exemplo: sen x = √3/2 ⇒ x = π/3 + 2kπ ou x = 2π/3 + 2kπ.

3. Expressões compostas

Uma equação pode envolver 2x, 3x ou outro argumento. Resolva primeiro a equação do argumento e só depois isole x, sem perder as famílias.

cos(2x) = 0 ⇒ 2x = π/2 + kπ ⇒ x = π/4 + kπ/2.

Para sen²x = 1/4, use sen x = ±1/2. A operação de extrair raiz exige considerar os dois sinais, salvo restrição adicional.

4. Inequações pelo círculo e pelo gráfico

O seno corresponde à coordenada vertical. Portanto sen x > 0 exatamente nas semicircunferências superiores, excluídos os extremos: 2kπ < x < (2k+1)π.

Para cos x ≥ 0, observe as partes à direita do eixo vertical. Em uma volta 0 ≤ x < 2π, a solução é [0,π/2] ∪ [3π/2,2π). Com periodicidade, repita os intervalos adequadamente.

Em inequações envolvendo tg, exclua seus pontos de indefinição (π/2 + kπ).

5. Checklist de validação

  • Reescreva com ângulos em unidades coerentes (graus ou radianos).
  • Verifique o intervalo solicitado e os pontos de fronteira.
  • Substitua uma solução em cada família na equação original.
  • Exclua denominadores nulos, quando houver divisão por seno ou cosseno.

Pratique e confira

Registre seu raciocínio antes de abrir o comentário.

1. Resolva sen x = 1/2 em 0 ≤ x < 2π.

x = π/6 ou x = 5π/6.

2. Resolva tg x = 1 para x real.

x = π/4 + kπ, k ∈ ℤ.

3. Resolva cos(2x) = 1.

x = kπ, k ∈ ℤ.

4. Determine as soluções de sen x < 0 em 0 ≤ x < 2π.

π < x < 2π. Os extremos ficam fora porque sen x = 0.
